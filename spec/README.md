# Spec

This folder is the memory of the project. The code shows what was built. These files show what was intended, what was asked and decided, and why.

| File | What it holds |
|---|---|
| [01-ideas.md](01-ideas.md) | Bela's ideas in his own words (I-nn) |
| [02-questions-and-answers.md](02-questions-and-answers.md) | Questions Claude asked and the answers (Q-nn). **OPEN** marks questions still waiting for an answer |
| [03-product-spec.md](03-product-spec.md) | The refined, current spec: concepts and requirements (FR-nn, NFR-nn) |
| [04-business-decisions.md](04-business-decisions.md) | What the product does, with the alternatives and the reasoning (BD-nn) |
| [05-architecture-decisions.md](05-architecture-decisions.md) | How it's built, with the alternatives and the reasoning (AD-nn) |

The files refer to each other by ID. For example, FR-13 points to AD-02, which records why Firefox downloads a copy on save.

Decisions marked **Claude, open** were made by Claude while building and still need Bela's review.

See [../CLAUDE.md](../CLAUDE.md) for how these files are kept up to date.
